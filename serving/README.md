# Serving

Use the system prompt in `system_prompt.txt` and temperature 0. The adapter needs the base model `unsloth/Llama-3.1-8B-Instruct`.

Load the adapter in Unsloth Studio (Chat tab) or with the Python example in the main README. The model is published on Hugging Face:
https://huggingface.co/qarnaynn/Llama-3.1-8B-triage-AntiHallucinate
